# 設計規範

更新：2026-10-25

這份文件記錄介面為什麼長這樣：幾個取捨、幾條不能破壞的規則，以及動效的分寸。

## 出發點

新分頁先給常用網站與搜尋，像 Safari 的起始頁；整理書籤的能力按需出現，像 Raindrop，而不是一打開就看到檔案總管。

介面要安靜。工具感來自密度與裝飾，兩者都應該退後。

## 品牌

書籤標籤標誌：深藍底，左側橘色書籤形標籤，白色線繩連到圓扣，右側白色筆記卡與灰色文字線。扁平線條，搭配「書野 Moorread」。原稿 `assets/icon.svg`，輸出 `assets/brand-mark.png` 與 `assets/icon.png`。

## 語意角色

變數在 `src/main.css`（基礎）與 `src/lib/appearance.ts`（各主題配色）。這裡只寫用途。

- `--primary`：晴空下取自標誌的天藍。只用於當前位置、主按鈕、懸停標題與焦點，不用於正文或大面積底色。
- `--foreground` / `--muted-foreground`：正文墨色與次級灰。網址、計數、說明一律用次級灰。
- `--card` + `--border`：書籤與資料夾卡片為白底細邊框；`--accent` 只做懸停與當前項底色。
- 字型：系統無襯線。只有時鐘與計數使用等寬數字（`tabular-nums`）。
- 中日韓字型：一律引用 `--cjk-sans` / `--cjk-serif`，依介面語言（`:root:lang()`）切換簡中、繁中、日文、韓文字形。每組同時列出 macOS、Windows、Linux 的字型；主題內不寫死 `PingFang SC` 這類單一地區字型。
- 側欄：未選中項用常規字重與 75% 正文色；當前項才用中等字重與全黑。
- 形狀：卡片高度跟內容走（共用 `cardSizeClass`，最小 76px），同一行由網格拉齊，不為空白預留固定高度。
- 圖示：導航用 lucide 線條圖示。系統分類與未改過圖示的目錄不用 emoji；使用者自選的 emoji 保留。目錄下拉使用 `categoryOptionLabel`。內建搜尋引擎顯示網站圖示（`SearchEngineIcon`）。書籤組未設圖示時用 `GroupStackGraphic`：組內前三個網站圖示像一手牌扇開，只有一個書籤時後面墊一張空白卡，懸停時扇得更開。書籤組空狀態仍用 `Layers`。

## 首頁

居中版面（新安裝預設）：日期與天氣一行、大號時鐘、大搜尋框、置頂一排（最多 10 個，搜尋時隱藏）。頂欄只留標誌、新增書籤、更多。新增書籤是白底描邊按鈕，藍色只留在圖示上，不與時鐘搶主角；工作台版面仍用實心主按鈕。

工作台版面：搜尋與時間天氣放在頂欄。既有設定升級後，預設為工作台。

時間與天氣都關閉時，居中的時間區整個收起，不留空位。

版面切換收在頂欄「更多操作」選單，關閉選單後才切換；設定頁也能切換。切換以 View Transitions 讓搜尋、時間與書籤網格從舊位置移到新位置；減少動態效果時直接切換。

居中版面往下滾，搜尋框一旦被頂欄遮住，頂欄就暫時接住搜尋與時間天氣，焦點跟著移上去；滾回頂部再交還原位。分類欄要吸頂時，高度取自頂欄實測值 `--header-height`，不能寫死。

置頂入口混放一般書籤與已啟用的書籤組，排序沿用置頂列表的混合規則，合計上限 10 項。組入口在懸停 100ms 或點擊後打開成員選單，移出再留 200ms 才收；兩種開法共用同一份選單，游標走進選單不算離開，懸停也不會奪走焦點。入口被懸停或以鍵盤聚焦時，預設圖示會展開，自訂圖示則微微上浮；開啟減少動態效果後，展開、上浮與按下縮放一併取消。「置頂」以外不參考開啟次數。

晴空加居中時，首屏背景跟隨天氣（晴的白天與夜晚、多雲、霧、雨、雪、雷暴），只佔時鐘後方並向下漸隱，不壓到書籤區。其他配色與工作台版面不顯示。

背景動效全由 CSS 完成，沒有圖檔，也不多發一個請求。雷暴以緩慢柔光交代，不用頻閃；開啟減少動態效果後全部停下。

## 設定頁

關於頁的標誌與產品資訊橫向排列。更新記錄收在版本號旁。原始碼與作者兩張卡片保留原樣：寬螢幕並排，窄螢幕縱向。版本號讀取擴充功能清單。

## 動效

只在內容變化時動。

開新分頁時，時鐘、搜尋、置頂一排依序上浮淡入。每張新分頁只演一次，切回居中不會重來。換分類或換檢視時，視口內的卡片接連淡入，相鄰兩張隔 24ms，整體最多錯開 240ms。分類欄的選中底色滑向新位置，空狀態淡入，資料夾圖示在懸停時翻開。

動效只有兩個來源：`src/lib/motion.ts` 的 `useStaggeredEntrance` 與 `useSlidingIndicator`，沒有引入動畫庫。開啟減少動態效果，或版面與卡片的 View Transition 正在進行時，內容動效一律停播。抓取前後畫面前先讓內容動效收尾；已經淡入完成的空狀態，切換後不該再淡一次。

版面、卡片與主題三種過渡都交給 `src/lib/view-transition.ts` 管生命週期：新過渡開始前先收掉舊的，更新只跑一次；就算畫面捕捉逾時，業務更新照樣套用。頁面在背景、使用者要求減少動態效果，或瀏覽器不支援 View Transitions，都直接更新不做轉場。卡片上的非同步操作失敗時，錯誤仍要回到呼叫端。

## 元件

- `HomeHero`：居中首屏。`HeaderWidget`、`SearchBar` 都有 `variant="hero"`，不另寫一份。
- `WeatherBackdrop`：天氣背景層。場景由 hero 內的 `HeaderWidget` 寫入 `useWeatherScene`；樣式在 `src/main.css` 的 `.weather-backdrop`。
- 資料夾卡片：實線邊框，與書籤卡片同一種表面。主題樣式透過 `.folder-card` 選擇，不依賴邊框類名。虛線只用於拖放目標這類「空位」。
- `FolderGraphic`：一個打開的小資料夾，露出目錄裡前三個書籤的網站圖示；沒有書籤時露出兩張紙。使用者選的 emoji 印在前片。懸停或聚焦卡片時，前片向外翻開、圖示向上散開。顏色全取主題變數，卡片尺寸不變。
- `BookmarkGridToolbar`：標題與計數。排序和批次管理收在「整理」選單；檢視切換保持可見。

## 不做的事

標題不加單側色條。計數為 0 就不顯示。排序與批次管理這類低頻操作，不佔首屏的常駐位置。
