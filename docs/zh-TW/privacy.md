# 隱私與權限

[English](./privacy.en.md) · [返回 README](../README.md)

這一頁只回答三件事：資料留在哪裡、什麼時候離開這台電腦、每個權限各自負責什麼。

書野 Moorread 不需要額外帳號，不使用第三方分析或追蹤 SDK，也不向開發者傳送使用統計。部分使用記錄（書籤開啟次數、最近開啟）只在本機保存，並依你的備份選擇隨完整快照傳送。

## 資料放在哪裡

| 資料 | 存放與同步 |
| --- | --- |
| 原生書籤名稱、網址與資料夾 | 由瀏覽器管理；跨裝置同步取決於瀏覽器的書籤同步設定 |
| 描述、標籤、自訂圖示、備用 URL、置頂、收件匣狀態、目錄圖示 | 本機儲存，預設透過瀏覽器同步跨裝置；可選擇欄位並啟用口令加密 |
| 書籤組的標題、描述、圖示、成員網址、組內名稱、順序與置頂 | 使用獨立的瀏覽器同步儲存，不受補充資料的欄位選擇與口令加密保護 |
| 介面與功能設定 | 使用瀏覽器同步儲存；AI 服務 Token 不參與同步 |
| 使用記錄（書籤開啟次數、最近開啟）、分頁工作階段、垃圾桶、操作歷史、快取 | 平時只存在目前這台裝置；建立完整快照並備份時，使用記錄會隨快照傳送至你設定的 Gist／WebDAV |
| AI 服務的 API Token | 只存本機，不參與同步或備份 |
| WebDAV 位址、帳號、應用密碼、備份加密口令、自動備份檢查狀態 | 只存本機，不參與瀏覽器同步或匯出的備份。**應用密碼只保留在目前瀏覽器工作階段**：擴充功能更新、重新載入或瀏覽器重新啟動後會清除，需重新輸入 |
| GitHub Gist 的 Token、Gist ID 與備份密碼 | 隨應用程式設定存放於 Chrome 同步儲存；啟用 Chrome 同步時，Chrome 同步服務會將這些設定傳到你的其他裝置。備份時，Token 作為驗證憑證送往 GitHub API，Gist ID 會出現在 GitHub API 的請求路徑；備份密碼不送往其他服務。Token 與備份密碼不寫入備份檔；Gist ID 為非憑證的資源識別，可能隨應用設定寫入快照 |

跨裝置同步需要兩台裝置使用同一個 Chrome 帳號、開啟瀏覽器同步，並安裝同一個擴充功能。同步狀態與補充資料的進階設定在「設定 → 資料與隱私」。

瀏覽器顯示已上傳，不代表另一台裝置已經收到；書野 Moorread 沒有獨立的雲端帳號或伺服器。

書籤組靠網址對應到既有書籤，不必信任不同裝置間可能不同的書籤 ID。移除一個書籤組，原生書籤仍留在原處。組本身的設定會一起進補充資料備份與完整快照。

## 什麼時候會連網

### 時間與天氣

時間依這台裝置的時區顯示。天氣則由你自行搜尋、自行挑城市，擴充功能不會讀取定位。

搜尋時會申請 Open-Meteo 兩個網域的可選存取權限，把城市關鍵詞送到 `geocoding-api.open-meteo.com`。設定完成後，所選城市的經緯度與溫度單位會送到 `api.open-meteo.com`。

服務端會看到一般網路請求所帶的 IP，但不會收到書籤或瀏覽記錄。

城市與顯示設定跟著瀏覽器設定同步，也包含在備份中；天氣結果只在本機快取 15 分鐘。關閉天氣後停止自動請求；未設定城市時不發出天氣請求。

可從首頁的時間天氣元件，或「設定 → 一般 → 時間與天氣」調整；也可在資料與隱私設定中撤銷可選網站權限。

### 網站圖示

顯示書籤卡片時，會按需把書籤網域送到 Google Favicon 服務，不傳路徑、查詢參數或頁面內容。遠端取得失敗時，回退到瀏覽器提供的網站圖示介面。

若為書籤或書籤組填了自訂圖片網址，瀏覽器會請求該圖片。

### 備用 URL

設定備用 URL 後，點擊書籤時會同時請求主網址與備用位址，選擇最先回應的入口。請求只會送到你填寫的那些位址。

### 網頁資訊與健康檢查

主動取得網頁描述或檢查連結時，才申請存取對應網站。請求只用來讀取網頁資訊，或判斷連結是否失效、重新導向。可選授權可在設定中撤銷。

### AI 分類

AI 分類需要自行設定 OpenAI 相容服務。執行時會送出書籤標題、移除查詢參數與錨點後的網址、描述、標籤、書籤目前所在的資料夾路徑、書籤內部識別碼、完整資料夾清單（ID 與路徑）、模型名稱與你設定的分類提示詞；資料由你選的服務處理，不會送出瀏覽記錄、開啟次數、分頁、垃圾桶或操作歷史。使用前請先看該服務的隱私政策。

每次開始分類與每次續跑前，介面都會先顯示獨立同意視窗，列出目的地主機、用途、上述實際傳送欄位、不會傳送的資料，以及 Token 與自動重試的處理方式。只有按下「同意並送出」才會發出請求；取消、關閉視窗、按 Esc 或同意流程未完成時，不會送出任何含書籤資料的請求。同意只在該次執行有效，不會保存，也不會沿用到其他執行；錯誤後按「繼續」必須重新同意。同一次執行內若請求暫時失敗，最多自動重試 2 次，送出內容相同，沿用該次同意。

連線測試與取得模型清單需要獨立的同意，只會把 Token 送到你設定的服務，不會送出書籤、資料夾清單或分類內容；該同意不能用於 AI 分類。

擴充功能先產生分類與移動預覽，確認後才修改書籤目錄。API Token 只存本機，不參與同步或備份。

### 網頁搜尋

切到網頁搜尋並送出關鍵詞時，查詢交給所選搜尋引擎；未指定時使用瀏覽器預設服務。

### WebDAV 備份

WebDAV 預設關閉。設定連線時，依伺服器位址申請可選網站權限，只向該位址送出帳號與應用密碼。

**應用程式密碼只保留在目前瀏覽器工作階段**，不寫入同步或備份；擴充功能更新、重新載入或瀏覽器重新啟動後會清除，需重新輸入一次，自動備份才會恢復。書籤與既有遠端備份檔不受影響。

位址必須是 HTTPS，只有本機測試例外允許 HTTP；重新導向一律不跟。測試連線只查目錄。真正的上傳發生在手動備份，或自動備份開啟之後，內容是完整快照：書籤樹、補充資料、書籤組、目錄圖示、使用記錄與介面設定。WebDAV 憑據、Gist Token／備份密碼和 AI Token 都不在其中；Gist ID 為非憑證的資源識別，可能隨應用設定寫入快照。

首次手動備份、首次啟用自動備份，以及首次測試連線、讀取遠端列表或還原前，介面會顯示揭露視窗：目的地伺服器、本次傳輸內容（上傳是完整快照；測試連線、遠端列表與還原只讀取，不會上傳快照）、憑證存放與傳送方式，並要求按下明確的同意按鈕。上傳與讀取（含測試連線、遠端列表、還原）分開同意，Gist 與 WebDAV 也各自獨立。拒絕同意、同意紀錄讀取失敗或紀錄格式無效時，一律不會匯出快照、不會發出任何請求。自動備份同樣必須先取得同意；升級後已勾選但缺少同意者會顯示「自動備份暫停中」，按一次「重新同意並恢復自動備份」即可恢復，原有設定保留，恢復當下不會立即上傳。

可在「資料與隱私」的「備份傳輸同意」撤回所有備份同意。撤回後不會再有任何自發傳輸（包含自動備份），手動上傳、測試連線、遠端列表與還原都會重新詢問；既有的 Gist／WebDAV 連線設定與憑證仍保留。要停止自動備份，撤回同意即可，不需要取消勾選或重新開啟設定頁。

自動備份預設關閉，只在開啟主頁並成功載入本機資料後檢查；達到設定間隔且內容有變化才上傳。不使用背景定時器、`alarms` 或系統通知。

這個口令預設留空，備份便以明文上傳。只要你填過並儲存一次，之後每份備份都會用本機口令派生金鑰（PBKDF2-SHA-256），再以 AES-256-GCM 在檔案離開電腦前加密整份快照。它連書籤組一起包住，範圍比只鎖補充資料的瀏覽器同步加密更大。

它與瀏覽器同步口令各管各的，只留在本機：不進同步，不寫進備份檔，也不放進請求標頭。改動或清空口令會讓自動備份的檢查點歸零，影響的只是往後的備份；先前產生的檔案，仍得用當時的口令解。

還原時先試本機口令；缺少或不符時可臨時輸入，僅在當前介面的記憶體中使用，不會改動已儲存的設定。解密失敗不會進入匯入流程。口令遺忘後，對應的加密檔無法還原。

遠端存取控制由你自行設定。每次成功上傳會建立新檔 `moorread-backup-YYYYMMDDThhmmssSSSZ-<UUID>.json`（UTC 時間戳，例如 `moorread-backup-20261011T100000000Z-<UUID>.json`），不覆蓋舊檔，也不會重複上傳固定名稱的最新檔。上傳成功後只保留最新 10 份，並嘗試刪除較舊的備份（包含可辨識的舊版 `yunji-tab-*` 檔名）；刪除為 best-effort，刪除失敗不影響已完成的備份，也不影響本機書籤。你仍可自行在雲端管理或刪除這些檔案。

同步記錄透過 WebDAV 目錄查詢讀取，只在介面記憶體中顯示，不在本機持久保存，也不另外上傳索引。其他裝置連上同一目錄即可讀取列表；舊版固定備份與 UUID 歷史檔也能辨識。

還原時會讀取所選檔案，限於目前帳號設定的同一目錄；伺服器提供強 ETag 時，以條件請求偵測檔案變化。格式校驗後先預覽，確認才匯入新資料夾。目錄查詢失敗會顯示錯誤；上傳失敗或內容未變化不產生遠端記錄。

本機只保留連線設定、上次檢查與成功時間、內容指紋與目前結果，用來控制自動備份頻率並避免重複上傳；舊版本機記錄會清理。清除連線設定會刪除本機憑據與狀態，不刪遠端檔案；可選網站授權可在資料與隱私設定另外撤銷。

### GitHub Gist 備份

Gist 備份預設關閉。開啟時需自行提供 GitHub Personal Access Token（需 `gist` 權限）。Token、Gist ID 與備份密碼隨應用程式設定存放於 Chrome 同步儲存；啟用 Chrome 同步時，Chrome 同步服務會將這些設定同步到你的其他裝置。備份時，Token 作為 GitHub API 的驗證憑證、Gist ID 作為目標 Gist 的識別，兩者都會送往 GitHub；備份密碼不送往其他服務，也不寫入備份檔。開發者不接收這些資料，但這不代表沒有第三方傳輸。

備份以單一檔案 `moorread-backup.json` 上傳到 `https://api.github.com/gists`，內容是完整快照（書籤樹、補充資料、書籤組、目錄圖示、使用記錄與介面設定）。本版快照 **不會包含** Gist Token、備份密碼、WebDAV 憑據、AI Token 或其他憑證欄位；同一個 Gist 只有這一份檔案，每次上傳會更新它，沒有多份歷史版本。

首次上傳前，介面會顯示揭露視窗：目的地是 GitHub Gist、會上傳完整快照、快照包含的資料類型，以及 Token／Gist ID／備份密碼存放於 Chrome 同步儲存並會跨裝置同步。需按下明確的同意按鈕才會上傳；拒絕同意時不會匯出快照、不會呼叫 GitHub API。測試 Gist 連線與從 Gist 讀取屬於獨立的讀取同意：揭露視窗會說明不會上傳快照、Token 會以 Authorization 標頭送到 `api.github.com`；未同意、同意紀錄讀取失敗或格式無效時，不會讀取也不會呼叫 API。撤回同意的方式與影響同 WebDAV，見上一節。

加密為選用功能；啟用時，快照會在本機以 PBKDF2-SHA-256（150,000 次迭代）派生金鑰，再以 AES-256-GCM 加密後才上傳。加密密碼隨應用程式設定存於 Chrome 同步儲存，不寫進備份檔、也不送進 GitHub API 請求標頭。未加密的備份會以明文形式存於你的 GitHub Gist；若曾上傳未加密備份，建議輪替你的 GitHub Token。

還原時從既有 gistId 讀取，自動偵測是否為加密 envelope（PBKDF2-SHA-256 + AES-256-GCM 結構）；若是加密備份，需輸入當時的口令才能解密。舊版未加密備份可直接還原。

## 權限用途

| 權限 | 用途 |
| --- | --- |
| `storage` | 儲存設定、本機補充資料與跨裝置同步資料 |
| `bookmarks` | 讀取與管理瀏覽器原生書籤 |
| `favicon` | 透過瀏覽器介面取得網站圖示 |
| `activeTab` | 在你使用快捷收藏或全域命令時讀取目前頁面 |
| `scripting` | 按需在一般網頁注入隔離的全域命令面板 |
| `contextMenus` | 提供「收藏此頁」右鍵選單 |
| `tabs` | 儲存與還原分頁工作階段，並重用主頁分頁 |
| `search` | 使用瀏覽器預設服務執行網頁搜尋 |
| `https://www.google.com/*` | 請求 Google Favicon 服務 |
| `https://*.gstatic.com/*` | 載入 Google 回傳的圖示資源 |
| `https://api.github.com/*` | 僅在啟用 Gist 備份時呼叫 GitHub API |
| 可選的 `http://*/*`、`https://*/*` | 按需存取網頁描述、連結檢查、AI 分類或 WebDAV 的指定網站與服務 |

全域命令面板預設關閉。開啟並使用瀏覽器層級快捷鍵時，需要在擴充功能的快捷鍵管理頁分配按鍵。

## 備份、還原與清理

「設定 › 資料與隱私」提供補充資料 JSON 的匯出、匯入與完整快照；WebDAV 使用同一份快照。

快照包含原生書籤樹、備用 URL 等補充資料、書籤組、目錄圖示、使用記錄與應用設定；不含分頁工作階段、垃圾桶、操作歷史、快取、AI Token、WebDAV 設定、Gist Token／備份密碼或任何加密口令。Gist ID 為非憑證的資源識別，可能隨應用設定寫入快照。

匯入前可預覽衝突。完整快照確認後，會還原到新的 `Moorread Restore ...` 資料夾，不會清空或覆蓋現有書籤。

同網址的補充資料與使用記錄回到快照中的值；書籤組依 ID 還原，同 ID 由快照取代，其他既有的組保留；應用設定由快照取代。備份檔中的 Gist 憑證欄位一律是淨化後的空值，因此還原不會清空你目前有效的 Token、Gist ID 與備份密碼：只有備份明確提供非空值時才採用，備份以 `null` 標記時才清除。

新建的原生書籤與還原後的擴充功能資料，仍依各自的同步設定傳到其他裝置；WebDAV 不接管瀏覽器同步。

WebDAV 口令管的是上傳到遠端的那份快照；從設定手動匯出的本機 JSON 不在保護範圍。匯出檔放在哪裡、給誰看，請自己留意。

透過書野 Moorread 刪除書籤或目錄時，會先存一份本機快照，可立即撤銷，或從「垃圾桶與歷史」還原。刪除快照保留 30 天。

設定中可分別清除使用記錄（書籤開啟次數、最近開啟）、網站圖示快取、分頁工作階段、垃圾桶與歷史、補充資料，以及可選網站授權。清除補充資料不會刪除原生書籤，但會清掉它的同步副本。書籤組是獨立資料，可在書籤組入口管理或刪除。

回報問題時，請隱藏 API Token、私人網址與瀏覽記錄。截圖與匯出的備份可能含有這些資料，不建議直接附在公開 Issue。
