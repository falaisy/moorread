# 備份與還原

[English](./backup.en.md) · [返回 README](../README.md)

備份的意義不在安心，而在出事時知道該打開哪一個檔案。這份文件按情境寫：換一台電腦、剛刪錯東西，或想回到上週的狀態。

入口都在「設定 › 資料與隱私」。可匯出、匯入補充資料，也可以用完整快照帶走書籤樹與相關設定。WebDAV 用的就是同一份完整快照。

## 快照包含什麼

| 會備份 | 不會備份 |
| --- | --- |
| 原生書籤樹、資料夾層級與順序 | 分頁工作階段、垃圾桶、操作歷史與快取 |
| 描述、標籤、自訂圖示、備用 URL、置頂與收件匣狀態 | AI API Token、WebDAV 連線設定與加密口令 |
| 書籤組與成員順序、目錄圖示、開啟次數、最近造訪時間、應用設定 | 瀏覽器同步的加密口令、Gist Token 與 Gist 備份密碼（快照只保留非憑證的 Gist ID） |

## 還原時會發生什麼

完整快照在還原前會先顯示預覽。確認之後，原生書籤樹會匯入一個新的 `Moorread Restore ...` 資料夾，現有書籤不動。

同網址的補充資料與使用記錄，會回到快照裡的值。書籤組依 ID 還原：同 ID 的組由快照取代，其他既有的組保留。應用設定也會被快照取代，但備份中的 Gist 憑證欄位一律是淨化後的空值，不會清空你目前有效的 Gist Token、Gist ID 或備份密碼；只有備份明確帶非空值時才採用，以 `null` 標記時才清除。

還原後的資料，仍照瀏覽器與擴充功能的同步設定參與跨裝置同步。

## 設定 WebDAV

1. 填目錄位址。預設是堅果雲 `https://dav.jianguoyun.com/dav/`，也可以換成其他 WebDAV 服務或子目錄。自訂目錄需先在雲端建立；遠端服務必須使用 HTTPS。
2. 填帳號與應用密碼。堅果雲的帳號是登入信箱，應用密碼在「帳戶資訊 › 安全選項 › 第三方應用管理」建立。
3. 需要時填「備份加密口令」，儲存後測試連線。第一次連線會申請該伺服器的網站存取權限。
4. 手動備份，或開啟「開啟新分頁時自動備份」。首次手動備份、首次啟用自動備份，以及首次測試連線、讀取同步記錄或還原前，介面會顯示揭露視窗：目的地伺服器、本次傳輸內容（上傳是完整快照；測試、列表與還原只讀取，不會上傳快照）與憑證儲存方式，需明確同意才會傳輸；拒絕同意、同意紀錄讀取失敗或格式無效時，不會匯出也不會發出請求。上傳與讀取分開同意。自動備份預設關閉；開啟後最短檢查間隔預設 24 小時，也可選 1、6 或 72 小時。達到間隔且內容有變化才上傳。沒有開啟主頁時不會定時執行，因此不需要 `alarms` 或通知權限。手動備份不受間隔與內容去重限制。

若升級後已勾選自動備份但缺少同意紀錄，設定頁會顯示「自動備份暫停中」，並提供「重新同意並恢復自動備份」按鈕；按下並同意後即恢復原有設定，不需要取消再勾選，也不會在恢復當下立即上傳，而是等下次開啟新分頁時才檢查。要撤回所有備份同意，可在「資料與隱私」的「備份傳輸同意」操作；撤回後自動備份停止、所有手動傳輸都會重新詢問，既有連線設定與憑證保留。

## 加密與口令

「備份加密口令」留空時，上傳的是普通 JSON。填寫並儲存一次之後，後續手動與自動備份都會沿用本機口令，以 AES-256-GCM 加密完整快照，書籤組也包含在內。

這個口令與補充資料的瀏覽器同步口令彼此獨立，只存在本機，不寫入遠端檔案或快照。

修改或清空口令，只影響之後的備份；舊檔案仍需要當初建立時的口令。還原時會先試本機口令；缺少或不符，可以臨時輸入。臨時口令不會改動已儲存的設定，解密成功後仍要預覽並確認。

口令遺忘後，對應的加密備份無法還原。

手動匯出的本機 JSON 不受這道口令保護，仍是明文。

## 歷史版本與跨裝置

每次備份只上傳一個獨立 JSON，檔名為 `moorread-backup-YYYYMMDDThhmmssSSSZ-<UUID>.json`，例如 `moorread-backup-20261011T100000000Z-<UUID>.json`。檔名含 UTC 時間（精確到毫秒）與隨機 UUID，不會覆蓋舊版本。

「同步記錄」直接讀取遠端目錄的檔案列表，依時間倒序顯示，可重新整理、還原最新備份，或還原指定的某一筆。首次讀取前需同意 WebDAV 讀取；未同意時不會查詢目錄。換裝置後連上同一個目錄就能看到記錄；加密檔案仍需對應口令。

上傳失敗或內容未變化時，只顯示目前狀態，不產生檔案記錄。

記錄不在本機持久儲存，也不另外上傳索引。舊版固定檔名 `yunji-tab-full-snapshot.json`、`yunji-tab-snapshot-<隨機 ID>.json` 與 `yunji-tab-backup-...` 也會列出，時間取伺服器的修改時間。

每次成功上傳後只保留最新 10 份備份，並以 best-effort 嘗試刪除較舊的檔案（含可辨識的舊版 `yunji-tab-*` 檔名）；刪除失敗不影響已完成的備份。你也可以自行在雲端清理。清除連線設定只會刪掉本機憑據、口令與檢查狀態，遠端檔案保留。

## 其他備份方式

除了 WebDAV，也可選擇：

- **GitHub Gist 備份**：用 Personal Access Token 上傳到自己的私人 gist，固定檔名 `moorread-backup.json`，每次上傳更新同一份、沒有多份歷史版本。首次上傳前會顯示揭露視窗並要求明確同意。Token、Gist ID 與備份密碼存於 Chrome 同步儲存，會隨 Chrome 同步到同帳號的其他裝置；備份密碼不會寫進備份檔或送往 GitHub。
- **Chrome 原生書籤雙向同步**：把 Moorread 書籤匯出到 Chrome 原生書籤（在 Other bookmarks 下建立 `Moorread Export` 子資料夾），或從 Chrome 書籤匯入（自動比對 url + title 去重）。
